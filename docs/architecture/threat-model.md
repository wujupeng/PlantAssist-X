# 威胁模型 — PlantAssist-X

> 状态：初始草案 · P0-03 实测后完善

## 1. 资产与信任边界

| 资产 | 位置 | 信任级别 |
| --- | --- | --- |
| 设备凭证 | 目标端本地存储 | 高敏感，需加密存储 |
| 会话凭证 | 内存，短时有效 | 高敏感，不可持久化 |
| 授权策略 | 协调服务 | 高敏感，仅管理员可改 |
| 审计日志 | 协调服务 / 本地 | 完整性受保护 |
| 屏幕帧数据 | 传输通道 | 机密性 + 完整性 |
| 远程输入流 | 传输通道 | 完整性 + 抗重放 |

## 2. 威胁清单

| 编号 | 威胁 | 对应安全约束 | 缓解措施 |
| --- | --- | --- | --- |
| T-01 | 未登记设备冒充已登记设备发起连接 | PA-R01, PA-R05 | 独立设备凭证 + 服务端身份验证 |
| T-02 | 仅凭 IP 地址获得控制权 | PA-R02 | 凭证绑定设备身份，不依赖 IP |
| T-03 | 凭证克隆导致多设备冒充同一身份 | PA-R01 | 凭证轮换 + 单活会话约束 |
| T-04 | 屏幕投送自动获得输入控制权 | PA-R04 | 权限分离，投送与控制独立授权 |
| T-05 | 远控程序隐藏，用户不知情 | PA-R03, PA-R06 | 目标端持续显示状态，不可静默关闭 |
| T-06 | 绕过 UAC / 安全桌面进行提权操作 | PA-R06 | 明确不支持安全桌面，不注入提权 |
| T-07 | 采集授权会话外的屏幕内容 | PA-R07 | 采集范围绑定授权会话，停止即释放 |
| T-08 | 断连后残留可用控制权限 | PA-R08 | 断线检测 + 立即停止接受新输入 |
| T-09 | 内网明文传输被嗅探 | PA-R10 | 所有会话强制加密 + 身份验证 |
| T-10 | 重放攻击注入历史输入 | PA-R09 | 抗重放序列号 / 时间戳校验 |
| T-11 | 普通操作员篡改审计日志 | FR-05 | 日志只追加 + 完整性校验 + 权限隔离 |
| T-12 | 过期凭证仍被接受 | PA-R05 | 凭证有效期校验 + 撤销列表检查 |

## 3. 攻击面

- **协调服务监听端口**：仅内网可达，强认证，最小 API。
- **目标端媒体/控制通道**：仅接受经协调服务授权的会话连接。
- **本地 IPC**：服务与用户进程间，双向认证 + 调用白名单。
- **设备凭证存储**：本地加密，防离线提取。

## 4. 负向测试要求（P0-03）

- 未登记设备连接 → 拒绝。
- 过期会话发起控制 → 拒绝。
- 撤权后发起输入 → 拒绝。
- 断线后注入输入 → 拒绝。
- 仅投送权限尝试控制 → 拒绝。
- 伪造身份 / 克隆凭证 → 拒绝并告警。
