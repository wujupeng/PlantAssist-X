# ADR-003：点对点安全协议

> 状态：已提出 · Gate B 补充 · 2026-10-28

## 背景

DG-04 审查要求明确两端如何验证对方、建立加密通道、防止重放及会话劫持。补充项 1 要求目标端独立验证授权凭证，不盲信协调服务通知。

## 决策

### 通道建立流程

1. 发起端向协调服务申请会话，服务做策略判定。
2. 服务签发短期会话凭证（绑定操作者/目标/会话ID/操作类型/有效期）。
3. 服务通知目标端会话已授权（含凭证摘要）。
4. 发起端与目标端点对点双向认证：互相验证设备证书 + 会话凭证签名。
5. 建立 TLS 1.3 或等效加密通道，使用临时密钥协商（前向安全）。

### 目标端独立验证（不盲信服务）

目标端独立验证：凭证签名、有效期、撤销状态、发起端身份一致性、授权范围一致性、会话唯一性。任一失败即拒绝并审计。

### 抗重放与防劫持

- 每会话单调序列号 + 时间戳窗口校验。
- 会话凭证单次使用，建立后即失效。
- 通道绑定会话ID，不接受替换。

## 后果

- 媒体与控制数据全部加密，增加少量握手开销。
- 目标端需预置协调服务公钥以验证凭证签名。
- 会话凭证短时有效，需续期机制（续期重新走策略判定）。
