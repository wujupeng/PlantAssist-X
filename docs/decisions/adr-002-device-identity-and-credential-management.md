# ADR-002：设备身份与凭证管理

> 状态：已提出 · Gate B 补充 · 2026-10-28

## 背景

DG-03 审查要求明确设备凭证签发、保护、轮换、撤销及协调服务失陷后的处置。PA-R01/R02/R05 要求不以单一可伪造属性作为身份凭据，且未登记/撤销/过期凭证必须被拒绝。

## 决策

### 设备身份由组合凭据绑定

- 设备唯一标识（UUID，签发时生成）+ 设备证书（协调服务签名）+ 设备私钥（本地保护）。
- 主机名/MAC/IP 仅作辅助显示与寻址，不参与授权判定。

### 凭证生命周期

签发 → 预部署分发 → 本地加密保护（DPAPI/CNG）→ 定期/泄露轮换 → 撤销列表 + 短期查询 → 卸载销毁。

### fail-closed 原则

协调服务不可用时，目标端不默认放行新会话；仅允许已建立会话按本地撤销缓存继续至凭证超时。

### 协调服务失陷处置

- 服务根密钥轮换 → 所有设备证书重签 → 旧证书全局失效。
- 设备预置服务证书指纹，不信任未知服务证书。
- 撤销列表缓存过期后 fail-closed。

## 后果

- 需要凭证签发/轮换/撤销基础设施（协调服务承担）。
- 需要本地受保护存储（DPAPI/CNG）。
- 卸载流程必须清除凭证。
- 协调服务离线时新会话不可建立（可接受的可用性折损，换取安全性）。
