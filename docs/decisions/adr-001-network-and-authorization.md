# ADR-001：网络部署与授权策略决策

> 状态：已确认 · 2026-10-28

## 背景

PlantAssist-X 面向企业自有网络中 20–200 台未加入统一域控的办公及产线终端。需确定网络部署方式、管理规模和授权策略，这三项决策直接影响部署成本和后续维护方式。

## 决策

### 1. 网络部署方式：纯企业内网直连

- 不依赖公网远控服务，不要求开放公网入站端口。
- 首期设置一台企业自有的轻量协调服务，负责注册、授权和会话发现。
- 屏幕数据尽量在两端直接传输；协调服务不转发屏幕视频，不承担媒体中继。
- 跨网段无法直连时，按企业网络策略评估自建中继（后续阶段）。

**理由**：产线与办公终端对第三方远控工具安全性不放心；内网直连降低外部依赖与数据外泄风险。

### 2. 管理规模：20–200 台终端

- 首期先验证 10 个并发会话。
- 再评估 200 台登记设备的在线状态管理与授权策略分发能力。

**理由**：覆盖企业小规模部署到产线批量管理的过渡区间，避免首期过度设计。

### 3. 目标端授权策略：管理员预先授权

- 企业部署时配置设备白名单和权限，连接时保留状态提示。
- 管理员预授权范围必须可配置（按产线 / 按终端 / 按操作员细分）。
- 不采用"每次会话单独确认"，以适应产线无人值守场景。
- 预授权必须有可验证的授权记录，不得仅凭 IP 地址授权（PA-R02）。

**理由**：产线终端可能无人值守，每次确认不可行；但预授权必须可审计、可撤销，避免隐蔽控制。

## 后果

- 需要部署一台轻量协调服务（非公网依赖）。
- 需要设备凭证管理机制（签发、轮换、撤销）。
- 需要管理员控制台进行策略配置与审计查询。
- 不需要域控基础设施。
- 不需要公网入站端口。
