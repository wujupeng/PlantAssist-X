# P0-01 限制清单

> 基于实测与策略查询得出的明确不支持/未验证边界

## 1. 明确不支持（设计边界）

| 编号 | 限制 | 原因 | 依据 |
| --- | --- | --- | --- |
| L-01 | UAC 安全桌面（提权弹窗）的远程查看与输入 | 安全桌面（Winlogon）属于独立桌面，Graphics Capture 无法采集；输入注入受 UIPI 限制 | PA-R06, windows-session-model.md |
| L-02 | Winlogon 登录界面的远程操作 | 同 L-01，登录界面在安全桌面 | PA-R$06 |
| L-03 | 跨用户会话同时操作多个桌面 | 首期仅支持当前活动会话；服务在 Session 0 无法直接访问任意用户桌面 | windows-session-model.md |
| L-04 | 通过后台服务直接操作用户桌面 GDI 资源 | Session 0 隔离，服务无交互桌面 | 实测隔离确认 |
| L-05 | Windows 10 Build < 18362 | 不支持 Windows Graphics Capture API | os-compatibility-matrix.md |
| L-06 | 阻止系统屏保/电源策略触发的锁屏 | 系统级策略，非应用可控；仅保证本系统不主动锁屏 | 实测 ScreenSaveActive=1 |

## 2. 本轮未验证（需补测）

| 编号 | 未验证项 | 原因 | 补测条件 |
| --- | --- | --- | --- |
| U-01 | Win10 目标机兼容性 | 仅单台 Win11 24H2 测试机 | 需 Win10 22H2 物理机/VM |

| U-03 | 安全桌面 UAC 采集边界 | 本机 PromptOnSecureDesktop=0 | 需 PromptOnSecureDesktop=1 测试机 |
| U-04 | 锁屏时采集行为 | 未实际锁屏（避免干扰用户） | 需专用隔离测试机 |
| U-05 | 解锁后会话恢复 | 同 U-04 | 同 U-04 |
| U-06 | 切换用户/多会话并存 | 同 U-04 | 同 U-04 |
| U-07 | 用户注销后会话清理 | 同 U-04 | 同 U-04 |
| U-08 | 多显示器采集 | 仅 1 屏环境 | 需 ≥2 显示器 |
| U-09 | 网络中断后权限清理 | 待实现后实测 | P0-04 |
| U-10 | 服务重启后无残留控制权限 | 当前零残留基线已确认，待实现后复测 | 实现后复测 |

## 3. 环境注意事项

| 编号 | 注意项 | 影响 |
| --- | --- | --- |
| E-01 | OrayIddDriver（向日葵）虚拟显示驱动存在 | 可能影响多显示器/采集枚举；P0-02 采集测试时需识别并排除或单独记录 |
| E-02 | AweSunService（向日葵服务）运行中 | 第三方远控已安装，环境现状；不影响本验证但说明环境已有第三方远控（印证项目背景） |
| E-03 | ConsentPromptBehaviorAdmin=0 | 管理员提权不提示，降低 UAC 弹窗频率；生产环境策略可能不同 |

## 4. 不支持清单（首期，与 windows-session-model.md 一致）

- UAC 安全桌面（提权弹窗）的远程查看与输入。
- Winlogon 登录界面的远程操作。
- 跨用户会话同时操作多个桌面（首期仅支持当前活动会话）。
- 通过服务进程直接操作用户桌面 GDI 资源。
- Windows 10 Build < 18362 的目标机。
- 阻止系统屏保/电源策略触发的锁屏（仅保证本系统不主动锁屏）。
