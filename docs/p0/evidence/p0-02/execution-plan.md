## 3. 技术验证原型设计

### 3.1 原型范围（最小化，非产品代码）

```
┌──────────────────────┐                    ┌──────────────────────┐
│  采集端               │  TCP 内网直连      │  显示端               │
│  ├─ Graphics Capture │ ──────────────→  │  ├─ 接收帧            │
│  ├─ 编码 (JPEG/H264) │  加密传输(原型简化)│  ├─ 解码              │
│  ├─ 帧时间戳         │                  │  ├─ 渲染显示          │
│  └─ 性能采集         │                  │  └─ 延迟计算          │
└──────────────────────┘                    └──────────────────────┘
```

### 3.2 模块清单

| 模块 | 实现 | 说明 |
| --- | --- | --- |
| 采集器 | Python + Windows.Graphics.Capture (WinRT) | 通过 Python winrt 绑定调用 Graphics Capture API |
| 编码器 | JPEG (Pillow) / H264 (Media Foundation) | 对比不同编码的帧率/延迟/带宽 |
| 传输 | TCP socket (内网直连) | 原型简化：帧头(时间戳+大小) + 帧数据 |
 | 解码器 | Pillow / Media Foundation | 对应编码器 |
| 显示器 | tkinter / OpenCV imshow | 窗口显示采集画面 |
| 性能计 | psutil + 时间戳 | CPU/GPU/内存/带宽/帧率/延迟 |

### 3.3 两条链路

| 链路 | 采集端 | 显示端 | 验证内容 |
| --- | --- | --- | --- |
| A: 屏幕投送 | 发起端 (HUNT) | 目标端 (181/12) | 发起端画面投送到目标端显示 |
| B: 远程查看 | 目标端 (181/12) | 发起端 (HUNT) | 目标端画面采集到发起端显示 |
