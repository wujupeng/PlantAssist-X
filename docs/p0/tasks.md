# P0 技术验证任务书

> 状态：待授权 · 按顺序执行 · 每项必须有可复现证据、测试记录及独立验收结果
>
> P0 目标：用最小化原型验证关键技术可行性，避免在 Windows 桌面会话、输入权限或屏幕同步上选错路线。**不开发完整产品。**

## P0-01：平台兼容性 — Windows 桌面会话验证

| 项 | 内容 |
| --- | --- |
| 编号 | P0-01 |
| 状态 | CONDITIONAL PASS |
| 任务 | 验证 Win11 发起端与 Win10/11 目标端的版本、权限和桌面采集能力 |
| 子任务 | 测试用户已登录、锁屏、解锁、切换用户、UAC 弹窗及注销；验证程序重启、网络中断后不遗留控制权限 |
| 交付物 | OS 兼容性矩阵、限制清单、测试日志 |
| 通过条件 | 所有声明支持的场景有实际证据；不支持场景有明确边界 |
| 验收 | 有条件通过；补测项见 evidence/p0-01/acceptance.md |

## P0-02：屏幕采集 — 双向画面技术验证

| 项 | 内容 |
| --- | --- |
| 编号 | P0-02 |
| 状态 | PENDING |
| 任务 | 验证目标端桌面捕获及发起端屏幕投送 |
| 子任务 | 比较 Windows Graphics Capture 与编码/解码方案；测试窗口切换、多显示器、分辨率变化、受保护内容；统计帧率、延迟、丢帧、资源占用 |
| 交付物 | 可运行最小原型、采样数据、技术选型记录 |
| 通过条件 | 两条画面链路均能重复演示，关键指标有原始测量记录 |

## P0-03：输入与授权 — 远程输入与安全会话验证

| 项 | 内容 |
| --- | --- |
| 编号 | P0-03 |
| 状态 | PENDING |
| 任务 | 在隔离测试机上验证授权会话中的鼠标键盘输入 |
| 子任务 | 测试未登记设备、过期会话、撤权和断线的拒绝行为；验证远程输入不能绕过目标端权限边界；确认投送权限不扩展为控制权限 |
| 交付物 | 权限状态机、负向测试结果、威胁模型 |
| 通过条件 | 所有未授权操作均被拒绝；断线及撤权后不接受新的控制输入 |

## P0-04：内网传输 — 直连网络与并发验证

| 项 | 内容 |
| --- | --- |
| 编号 | P0-04 |
| 状态 | PENDING |
| 任务 | 验证同网段和跨网段直连条件 |
| 子任务 | 测试 Windows 防火墙规则、端口策略、丢包、延迟、网络恢复；评估 10 并发会话及 200 台设备登记/在线状态；记录带宽和编码资源消耗 |
| 交付物 | 网络拓扑、端口清单、性能测试报告 |
| 通过条件 | 不开放公网入站端口即可完成内网测试；不满足直连时明确报告失败，不静默切换至第三方服务 |

| 项 | 内容 |
| --- | --- |
| 编号 | P0-05 |
| 状态 | PENDING |

| 子任务 | 验证低权限运行、日志保护、服务停止和客户端退出；评估不同 Windows 版本、补丁、显卡驱动兼容性 |

## 执行约束

- 一项任务、一项验收 Gate，未经批准不扩大开发范围。
- 每项任务固定一个提交基线，防止验收过程中悄然扩大范围。
- 不允许把未验证事项标为 PASS。
