# P0 总体验收 Gate

> P0 完成后必须同时满足以下条件，才可提交产品开发授权申请。

## Gate 矩阵

| Gate 项 | 必须提交的证据 | 通过条件 | 状态 |
| --- | --- | --- | --- |
| G0-1 技术可行性 | 可运行原型、系统版本记录 | 两条画面链路得到验证 | PENDING |
| G0-2 Windows 兼容性 | 测试矩阵、限制清单 | 声明支持的会话场景通过 | PENDING |
| G0-3 安全授权 | 威胁模型、负向测试日志 | 不存在已知可复现的未授权控制路径 | PENDING |
| G0-4 性能 | 原始测量数据、测试环境说明 | 达到经确认的性能基线，或由 PM 正式调整目标 | PENDING |
| G0-5 运维部署 | 安装、撤权、卸载测试记录 | 能够管理设备凭证和会话生命周期 | PENDING |
| G0-6 文档完整性 | 需求、架构、测试和风险记录 | 结论可复核，未验证事项没有被标为 PASS | PENDING |

## 阻断规则

任一以下情况均不得将 P0 判定为 PASS：

- 关键安全测试失败。
- 授权边界不明确。
- 目标端状态提示不可可靠实现。
- 核心画面链路没有实测证据。
- 未验证事项被标为 PASS。
