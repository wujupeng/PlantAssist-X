# PRD v0.1 — PlantAssist-X 需求规格书

> 状态：已提出 · 待设计 Gate 冻结 · 最终阈值由 P0 实测校准

## 1. 用户角色与权限

| 角色 | 允许操作 | 禁止事项 |
| --- | --- | --- |
| 系统管理员 | 注册/撤销设备、分配权限、查看审计日志 | 默认不获得所有设备的隐式控制权 |
| 远程协助人员 | 连接授权终端、查看画面、执行获授权输入 | 控制未授权设备、扩大自身权限 |
| 屏幕投送发起人 | 共享自己的屏幕、停止投送 | 未经授权控制目标端输入 |
| 目标端当前用户 | 查看会话状态、按策略停止会话 | 无 |
| 审计人员 | 查询安全事件和会话记录 | 修改历史审计记录 |

> 管理员预授权的具体范围必须可配置，例如：某个操作员可以控制指定产线的指定终端，而不是自动拥有全部 200 台终端的控制权限。

## 2. 强制安全边界

| 编号 | 强制约束 |
| --- | --- |
| PA-R01 | 不允许未授权设备发起远程控制。 |
| PA-R02 | 管理员预先授权必须有可验证的授权记录，不得仅凭 IP 地址授权。 |
| PA-R03 | 目标端持续显示会话状态，支持管理员或获授权用户终止会话。 |
| PA-R04 | 屏幕投送与远程控制权限分离，不能因共享画面自动获得输入权限。 |
| PA-R05 | 默认拒绝未知设备、过期凭证、无效身份和无法验证的会话。 |
| PA-R06 | 不隐藏远控程序，不绕过 UAC、安全桌面、登录认证或系统安全策略。 |
| PA-R07 | 不采集与授权会话无关的屏幕，不默认录制或保存视频。 |
| PA-R08 | 断连、撤权或服务异常时，立即停止接受新的远程输入。 |
| PA-R09 | 所有远程输入均受授权会话、目标设备和用户会话范围约束。 |
| PA-R10 | 纯内网不等于可信网络；所有会话必须进行身份验证和加密。 |

## 3. 功能需求与验收标准

### FR-01：设备注册与身份认证

- 每台终端具有独立设备标识和设备凭证。
- 未登记终端不能进入可控设备列表。
- 设备凭证可撤销、轮换；克隆凭证不能让两台设备同时冒充同一设备。
- 不以主机名、MAC 地址或 IP 地址单独作为身份凭据。

**验收**：未登记设备、撤销凭证、伪造身份和过期凭证的连接测试全部拒绝。

### FR-02：远程查看与输入控制

- 支持目标桌面实时显示、鼠标和键盘输入。
- 目标端不因建立会话主动锁屏、注销或切换用户。
- 屏幕分辨率、缩放、双显示器和输入焦点应有明确处理规则。
- UAC 安全桌面等特殊界面必须明确提示不支持或需要单独的合规处理方式。

**验收**：在目标端正常桌面完成窗口切换、文本输入、鼠标操作及断连测试；不允许把特殊安全桌面的能力未经验证地宣称为已支持。

### FR-03：发起端屏幕投送

- 共享发起端的指定屏幕或指定窗口。
- 目标端在独立、可见的投送窗口显示画面。
- 发起端的鼠标移动、窗口切换及操作结果随采集帧更新。
- 停止共享后释放采集资源，恢复目标端原有工作界面。

**验收**：画面内容、窗口切换、分辨率变化和停止共享均可重复验证；投送不得意外获得目标端输入控制权限。

### FR-04：授权和会话生命周期

- 管理员可以配置设备、人员、允许操作类型和有效期限。
- 会话凭证短时有效，并绑定操作者、目标设备及会话。
- 支持立即撤销、超时结束和断线清理。
- 目标端状态提示不能被普通远程输入静默关闭。

**验收**：授权前、授权后、授权过期、撤权后、断网后均按预期执行；撤权后不再接受新的控制输入。

### FR-05：安全审计

- 记录会话申请、授权依据、建立、结束、失败、撤权及安全异常。
- 日志不默认保存屏幕内容、密码、键盘输入文本或其他敏感内容。
- 普通操作员不得修改或删除审计记录。

**验收**：使用测试事件核对日志完整性、时间顺序、权限边界和篡改检测。

## 4. 非功能需求（初始目标）

| 指标 | 初始验收目标 | 测量条件 |
| --- | --- | --- |
| 远程查看帧率 | 目标 20–30 FPS | 1080p、常规办公动态画面 |
| 端到端画面延迟 | P95 ≤ 200 ms | 有线内网、单会话，固定测试场景 |
| 屏幕投送延迟 | P95 ≤ 200 ms | 同上，采集至目标显示 |
| 会话并发 | 先验证 10 个并发会话 | 再评估 200 台登记设备的管理能力 |
| 网络恢复 | 恢复后重新认证 | 不自动恢复已撤销的权限 |
| CPU/GPU 占用 | P0 建立基线后冻结 | 记录采集端、编码端和显示端资源 |
| 安全性 | 所有规定的负向测试通过 | 不存在绕过授权的可复现路径 |

> 这些是待验证的工程目标，不是已实现的性能承诺。尤其是 200 ms 延迟，需要明确测试机器性能、分辨率、网络 RTT 和画面复杂度。
