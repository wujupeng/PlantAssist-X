## 项目定位

面向企业自有网络中 **20–200 台未加入统一域控的办公及产线终端** 的 Windows 远程协助与屏幕投送系统。

### 核心业务目标

- **远程协助**：Windows 11 发起端查看 Windows 10/11 目标终端桌面，并在已授权会话中传递鼠标和键盘操作。
- **屏幕投送**：发起端将自己的屏幕实时投送至目标端现有用户桌面可见的窗口，发起端的操作随画面同步显示。
- **不干扰现有工作**：不因建立会话主动锁屏、注销或切换目标端用户。
- **无域控部署**：通过独立的设备注册、管理员授权及本地网络发现机制管理终端。
- **内网优先**：不依赖第三方公网远控平台，不要求开放公网入站端口。
- **可审计**：记录设备身份、授权依据、会话起止时间、操作者及安全事件。

### 设计原则

被控端可以不锁屏、不打断当前工作，也不需要加入域控；但**静默运行不应等于隐蔽控制**。通过企业管理员预先安装、设备白名单、授权策略和可审计日志实现低干扰管理，而不是隐藏远控程序、绕过用户授权或秘密采集屏幕。

> **产品边界**：PlantAssist-X 是企业远程协助工具，不是隐蔽监控软件，也不是绕过 Windows 安全边界的系统控制器。

## 开发顺序

1. **P0**：技术验证与设计 Gate — 验证 Win11 到 Win10/11 的桌面采集、远程显示、当前用户会话兼容性及内网延迟。
2. **P1**：双向屏幕功能 — 远程查看目标桌面 + 发起端屏幕投送。
3. **P2**：远程输入与权限控制 — 鼠标键盘控制、会话授权、撤销、断线恢复及审计。
4. **P3**：小规模试点 — 多网段连接、性能、长时间运行、并发及异常恢复测试。
5. **P4**：企业部署 — 安装包、设备注册工具、管理员控制台、升级和卸载机制。
